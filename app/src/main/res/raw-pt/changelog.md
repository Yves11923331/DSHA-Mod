# DSHA dsha.v1 / build308

- Primeira build DSHA em coexistência: baseada no upstream build307, pacote `dsga.mod`, totalmente isolado do `dsh.android.client` original; ambos podem ser instalados juntos sem compartilhar dados.
- Dock horizontal: tela virtual 16:9 com presets 1280/1024/854, barras do sistema ocultas, respeitando o recorte.
- Tela sempre ligada: novo interruptor acima do cartão de energia nas configurações, desligado por padrão, ciclo de vida global cobrindo web/terminal/horizontal.
- Ícone do launcher trocado pelo conjunto completo de inverno Pro (5 densidades x 5 nomes mais frente/fundo adaptativos, fundo `#798AA3`).
- Nome de exibição DSHA, nome da versão `dsha.v1`, código da versão 308.
