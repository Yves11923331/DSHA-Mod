# DSHA dsha.v1 / build308

- Première build DSHA en coexistence : basée sur upstream build307, paquet `dsga.mod`, totalement isolé du `dsh.android.client` d'origine ; les deux s'installent côte à côte sans partage de données.
- Dock paysage : écran virtuel 16:9 avec préréglages 1280/1024/854, barres système masquées, gestion de l'encoche.
- Écran toujours allumé : nouvel interrupteur au-dessus de la carte alimentation dans les réglages, désactivé par défaut, cycle de vie global couvrant web/terminal/paysage.
- Icône du lanceur remplacée par le jeu complet hiver Pro (5 densités x 5 noms plus premier/second plan adaptatifs, fond `#798AA3`).
- Nom affiché DSHA, nom de version `dsha.v1`, code de version 308.
