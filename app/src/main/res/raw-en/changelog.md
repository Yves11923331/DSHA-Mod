# DSHA dsha.v1 / build308

- First DSHA coexisting build: based on upstream build307, package `dsga.mod`, fully isolated from the original `dsh.android.client`; both install side by side with no shared data.
- Landscape Dock: 16:9 virtual screen with 1280/1024/854 presets, system bars hidden, cutout-aware.
- Keep-screen-on: new switch above the power card on the settings home, off by default, global lifecycle covering web/terminal/landscape.
- Launcher icon switched to the full winter Pro asset set (5 mipmap buckets x 5 names plus adaptive foreground/background, background `#798AA3`).
- Display name DSHA, version name `dsha.v1`, version code 308.
