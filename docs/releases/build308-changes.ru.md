# DSHA dsha.v1 / build308

- Первая сборка DSHA для совместной установки: на основе upstream build307, пакет `dsga.mod`, полностью изолирован от исходного `dsh.android.client`; обе версии устанавливаются одновременно, данные не пересекаются.
- Ландшафтный Dock: виртуальный экран 16:9 с пресетами 1280/1024/854, скрытые системные панели, учёт выреза.
- Постоянный экран: новый переключатель над карточкой питания в настройках, по умолчанию выключен, глобальный жизненный цикл для веб/терминала/ландшафта.
- Значок запуска заменён на полный зимний набор Pro (5 плотностей x 5 имён плюс адаптивные передний/задний планы, фон `#798AA3`).
- Отображаемое имя DSHA, имя версии `dsha.v1`, код версии 308.
